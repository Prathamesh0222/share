# Typen

A modern, full-featured content sharing and blogging platform built with Next.js, Bun, and Prisma. Share your thoughts, discover content, and engage with a community of writers and readers.

![Alt text](./public/hero_section.png "Typen")

## Features

- **Rich Text Editor**: Create beautiful posts with TipTap's powerful rich text editor
- **AI-Powered Summaries**: Automatically generate TLDR summaries for your posts using Google GenAI
- **Social Engagement**: Like, bookmark, and comment on posts
- **Tag System**: Organize and discover content through tags
- **User Profiles**: Showcase your content and activity
- **Discover Feed**: Explore trending and popular content
- **Image Uploads**: Seamlessly upload and manage images with Cloudinary
- **Table of Contents**: Auto-generated navigation for long-form content
- **Dark Mode**: Beautiful dark and light themes
- **Authentication**: Secure authentication powered by Better Auth

## Tech Stack

- **Framework**: Next.js 16 with App Router
- **Package Manager:** Bun
- **Database**: PostgreSQL with Prisma ORM
- **Authentication**: Better Auth
- **Rich Text Editor**: TipTap
- **Styling**: Tailwind CSS
- **Animations**: Motion
- **Image Management**: Cloudinary
- **AI Integration**: Google GenAI
- **UI Components**: Shadcn UI
- **State Management**: TanStack Query
- **Language**: TypeScript
